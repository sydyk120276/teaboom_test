# Teaboom — карточка товара

Тестовое задание: верстка верхней части карточки товара интернет-магазина
[Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun) (Ананасовый улун).

Статический сайт: HTML5 + CSS + ванильный JavaScript, без сборки и без бэкенда.

## Запуск

Сборка не нужна — достаточно открыть [index.html](index.html) в браузере.

Просто открыть файл:

```
index.html
```

## Что реализовано

- галерея товара (миниатюры + смена главного изображения + лайтбокс Fancybox);
- переключение фасовки (100 / 500 / 1000 / 5000 г) с обновлением цены,
  старой цены, артикула и наличия;
- табы «Описание / Свойства / Отзывы»;
- адаптивная вёрстка: desktop 1440px, tablet 768px, mobile 375px.
